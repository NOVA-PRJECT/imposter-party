# 🕵️‍♂️ Imposter Group

> **Same room. Own phone. Find the imposter!**

**Imposter Group** is an exciting, fast-paced local multiplayer word game designed for friends and families hanging out in the same room. No app downloads, no sign-ups, and no hassle — simply open the website on any smartphone browser, enter a room code, and start playing instantly!

---

## ✨ Key Features

- 📱 **Play on Any Smartphone:** Mobile-first, sleek design optimized for all mobile web browsers.
- 🚀 **Instant Room Creation:** Create a private room in seconds with a shareable 6-character code.
- 🎨 **Avatar Color Customization:** Pick your unique player color from a rich 18-color palette.
- 📚 **Diverse Word Packs:** Play across multiple categories including General Knowledge, Occupations, House Items, Celebrities, and Animals.
- ✏️ **Custom Word Builder:** Create custom secret words, meanings, and hints live in the lobby to include inside jokes!
- 💡 **Hint Mode:** Enable optional 1-word clues for the Imposter to help them blend in.
- 📖 **Meaning Mode:** Provide definitions for Crewmates to ensure everyone knows the word.
- ⏱️ **Custom Voting Timers:** Set timed voting rounds for fast-paced pressure or leave timers off for casual play.
- 🚨 **Real-Time Synchronized Play:** Live turn progression, real-time vote tracking, and dramatic identity reveals across all connected devices.
- 👑 **Host Control & Auto-Migration:** Full control over game settings with automatic host transfer if a player leaves.

---

## 🎮 How to Play

### 1. Join the Room
* **Host** taps **Create Room** and shares the 6-letter room code.
* **Players** enter the code on their own phones to join.
* Everyone chooses their avatar color.

### 2. Secret Role Assignment
* 🟢 **Crewmates** secretly receive the secret word (e.g., *"Volcano"*).
* 🔴 **Imposters** receive a secret alert that they are the Imposter (and an optional 1-word hint).

### 3. Discussion Phase
* Talk out loud in the physical room! Give subtle clues to prove you know the word without giving it away to the Imposter.
* The Imposter must listen carefully, fake confidence, and pretend they know the word.

### 4. Voting & Elimination
* The host calls a vote when discussion ends.
* Players cast their secret votes on their phones.
* The player with the most votes is eliminated and their identity is revealed!

### 5. Win Conditions
* 🟢 **Crewmates Win:** If all Imposters are successfully voted off.
* 🔴 **Imposters Win:** If Imposters equal or outnumber the surviving Crewmates.
